# ESG Mapper

Публичная версия сайта: https://SaroyanAram.github.io/esg-mapper/

Корень этого репозитория - содержимое папки `site/dist/`. В репозиторий специально не попадают `Материалы/`, черновики, исходные таблицы и переписки.

Оптический прибор первого экрана работает в браузере: это оптимизированные WebP-рендеры Blender-сцены, CSS-движение линз и интерактивные вкладки «Баланс / ОФР / ОДДС». Исходный `.blend` хранится в `site/asset-source/` и не нужен для показа сайта.

## Как обновить сайт

 Основной рабочий поток - из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Message "Обновил кейсы"
```

Скрипт сам:

1. копирует `content/site-content.json` в `site/dist/data/site-content.json`;
2. проверяет, что JSON валидный;
3. коммитит изменения в этом репозитории и делает `git push`.

Через 1-2 минуты обновление появится по публичной ссылке. Если браузер показывает старую версию, нажмите Ctrl+F5.

## Ручное обновление

```powershell
cd "site\dist"
git add -A
git commit -m "Обновление сайта"
git push
```

## Локальный просмотр

Из корня проекта:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory site/dist
```

Затем откройте http://127.0.0.1:8765/ . Прямо с диска (`file://`) сайт не работает: браузер блокирует загрузку локального JSON через `fetch`.

## Важно

- Источник контента - `content/site-content.json` в корне проекта. Не редактируйте копию в `data/` вручную: следующий запуск `publish.ps1` перезапишет её.
- Все пути в сайте относительные, поэтому проект корректно работает на адресе вида `/esg-mapper/`.
- Публикация настроена через GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
