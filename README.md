# ESG Mapper

Основная версия: https://SaroyanAram.github.io/esg-mapper/ — светлый «живой атлас» v3 с объёмной Люпой, отрисованной в Blender.

Архивы: https://SaroyanAram.github.io/esg-mapper/v1/ — первая публикация; https://SaroyanAram.github.io/esg-mapper/v2/ — полная копия предыдущей публикации. Оба адреса остаются доступными для сравнения и отката.

Корень этого репозитория - содержимое папки `site/dist/`. Материалы, переписки и исходники в репозиторий не попадают.

Сайт статический: локальный JSON, относительные пути, без сборки, CDN, внешних API и аналитики. Все 12 кейсов, четыре моста, пять вопросов, методология и источники берутся из `data/site-content.json`. Восемь декоративных WebP подключаются флагами в `assets/avatar/manifest.json`; при выключенном флаге остаётся локальная SVG/DOM-заглушка.

## Как обновить сайт

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Message "Обновил кейсы"
```

Скрипт копирует `content/site-content.json` в `data/` основной версии и в `data/` архива `v1/`, проверяет JSON, коммитит и пушит `site/dist`. Архив `v2/` не перезаписывается: это снимок предыдущей публикации. Через 1-2 минуты изменение появится по публичной ссылке. Если браузер показывает старую версию, нажмите Ctrl+F5.

## Локальный просмотр

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory site/dist
```

Затем откройте http://127.0.0.1:8765/ . Прямо с диска (`file://`) сайт не работает: браузер блокирует `fetch` локального JSON.

## Важно

- Источник контента - `content/site-content.json` в корне проекта. Копии в `data/` не редактируют вручную.
- Все пути относительные, поэтому сайт работает на адресе вида `/esg-mapper/`.
- GitHub Pages настроен: `main` → `/ (root)`, файл `.nojekyll` присутствует.
- Перевод v2 в корень и создание архива v1 описаны в `promote-v2.ps1`; перед v3 полная копия v2 сохранена в `v2/`.
