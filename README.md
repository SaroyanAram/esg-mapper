# ESG Mapper

Основная версия: https://SaroyanAram.github.io/esg-mapper/ — светлый «живой атлас» v6: разные смысловые образы E/S/G и мостов, цветная кодировка правил, яркий радар, живая контрольная точка; Люпа-прибор, полоса прогресса и параллакс мостов сохранены.

Архивы: https://SaroyanAram.github.io/esg-mapper/v1/ — первая публикация; https://SaroyanAram.github.io/esg-mapper/v2/ — тёмная визуальная версия; https://SaroyanAram.github.io/esg-mapper/v3/ — полная копия неподвижного светлого атласа; https://SaroyanAram.github.io/esg-mapper/v4/ — полная копия атласа в движении; https://SaroyanAram.github.io/esg-mapper/v5/ — полная копия версии с Люпой-прибором и первыми ожившими актами. Все адреса остаются доступными для сравнения и отката.

Корень этого репозитория - содержимое папки `site/dist/`. Материалы, переписки и исходники в репозиторий не попадают.

Сайт статический: локальный JSON, относительные пути, без сборки, CDN, внешних API и аналитики. Все 12 кейсов, четыре моста, пять вопросов, методология и источники берутся из `data/site-content.json`. Восемь декоративных WebP и два анимационных ассета подключаются флагами в `assets/avatar/manifest.json`; при выключенном флаге остаётся локальная SVG/DOM-заглушка. Hero использует `atlas-loop.webm` с запасным MP4 и poster; Люпа - анимированный WebP. При `prefers-reduced-motion` включается статика.

## Как обновить сайт

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Message "Обновил кейсы"
```

Скрипт копирует `content/site-content.json` в `data/` основной версии и в `data/` архива `v1/`, проверяет JSON, коммитит и пушит `site/dist`. Архивы `v2/` и `v3/` не перезаписываются: это снимки прошлых публикаций. Через 1-2 минуты изменение появится по публичной ссылке. Если браузер показывает старую версию, нажмите Ctrl+F5.

## Локальный просмотр

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory site/dist
```

Затем откройте http://127.0.0.1:8765/ . Прямо с диска (`file://`) сайт не работает: браузер блокирует `fetch` локального JSON.

## Важно

- Источник контента - `content/site-content.json` в корне проекта. Копии в `data/` не редактируют вручную.
- Все пути относительные, поэтому сайт работает на адресе вида `/esg-mapper/`.
- GitHub Pages настроен: `main` → `/ (root)`, файл `.nojekyll` присутствует.
- Перевод v2 в корень и создание архива v1 описаны в `promote-v2.ps1`; перед v3 полная копия v2 сохранена в `v2/`, перед v4 - полная копия v3 в `v3/`, перед v5 - полная копия v4 в `v4/`, перед v6 - полная копия v5 в `v5/`.
- Движение нижних актов живёт в `motion.js` и CSS. При `prefers-reduced-motion` декоративные петли отключены, контент и интерактив доступны без анимации.
