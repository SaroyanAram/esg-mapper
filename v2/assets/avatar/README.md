# Кадры из GPT

Сюда кладутся готовые изображения по файлу `Материалы/Промпты для GPT.md`. Пока флаги выключены, сайт показывает локальные SVG-заглушки того же смысла и не запрашивает эти файлы.

## Как подключить

1. Переименуй файлы по таблице и положи в эту папку. Если формат не WebP, OpenCode перекодирует.
2. В `manifest.json` поставь `true` у соответствующих кадров.
3. Обнови страницу. Manifest запрашивается без кэша, перезагрузки достаточно.

| Ключ | Файл | Где появляется |
|---|---|---|
| `hero` | `hero-backdrop.webp` | Фон первого экрана поверх контурной карты |
| `lupa` | `lupa.webp` | Заменяет векторную Люпу в первом акте и на карте следов |
| `e`, `s`, `g` | `portal-e.webp`, `portal-s.webp`, `portal-g.webp` | Фоны карточек источников сигнала |
| `report` | `report-sheet.webp` | Лист отчётности на липкой сцене каталога |
| `result` | `result-map.webp` | Фон карточки результата квиза |
| `outro` | `outro.webp` | Фон финального блока с источниками |

Изображения остаются декоративными: весь текст, подписи и стандарты живут в HTML и берутся из `data/site-content.json`.
