# ESG Mapper

Основная версия: https://SaroyanAram.github.io/esg-mapper/ — визуальная история «След сигнала» с Люпой-линзой.

Старая версия сохранена как архив: https://SaroyanAram.github.io/esg-mapper/v1/ . Она не используется для сдачи, но остаётся доступной для сравнения.

Корень этого репозитория - содержимое папки `site/dist/`. Материалы, переписки и исходники в репозиторий не попадают.

Сайт статический: локальный JSON, относительные пути, без сборки, CDN, внешних API и аналитики. Все 12 кейсов, четыре моста, пять вопросов, методология и источники берутся из `data/site-content.json`. Изображения в `assets/avatar/` подключаются флагами в `assets/avatar/manifest.json`; декоративные SVG-заглушки остаются на месте, когда флаг выключен.

## Как обновить сайт

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Message "Обновил кейсы"
```

Скрипт копирует `content/site-content.json` в `data/` основной версии и в `data/` архива `v1/`, проверяет JSON, коммитит и пушит `site/dist`. Через 1-2 минуты изменение появится по публичной ссылке. Если браузер показывает старую версию, нажмите Ctrl+F5.

## Локальный просмотр

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory site/dist
```

Затем откройте http://127.0.0.1:8765/ . Прямо с диска (`file://`) сайт не работает: браузер блокирует `fetch` локального JSON.

## Важно

- Источник контента - `content/site-content.json` в корне проекта. Копии в `data/` не редактируют вручную.
- Все пути относительные, поэтому сайт работает на адресе вида `/esg-mapper/`.
- GitHub Pages настроен: `main` → `/ (root)`, файл `.nojekyll` присутствует.
- Перевод v2 в корень и создание архива v1 описаны в `promote-v2.ps1` в корне проекта.
